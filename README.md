# Brasa Viva — página de pollo a la brasa

Sitio estático adaptable para una pollería, con un carrusel de platos interactivo que se puede arrastrar con mouse o touch y controlar con teclado.

## Ejecutar

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático. No hay dependencias de JavaScript ni proceso de build.

## Rendimiento y accesibilidad

- Sin framework, librerías 3D ni imágenes pesadas: la escena usa CSS y el carrusel se actualiza con `requestAnimationFrame`.
- Diseño responsive, navegación semántica y controles de carrusel accesibles.
- Respeta `prefers-reduced-motion`.
- Las fuentes de Google son opcionales; se usan fuentes del sistema como alternativa.

Personaliza el nombre, dirección, precios y enlace de ubicación en `index.html`.
